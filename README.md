# 🎂 Baking Bistro - Premium Custom Cake Design Studio

A modern, luxury bakery website designed for custom cake creation and consultation.

## ✨ Features

### 🏠 Homepage Sections
- **Hero Section**: Compelling headline with premium imagery and dual CTAs
- **Why Baking Bistro**: Four key value propositions with hover animations
- **Custom Cake Builder**: Multi-step form for custom cake orders
- **Gallery**: Elegant masonry grid with category filtering
- **Process Section**: 4-step visualization of the cake creation journey
- **Testimonials**: Luxury-styled customer reviews
- **FAQ**: Comprehensive Q&A section with accordion interactions
- **Contact Section**: Location, hours, and contact form

### 🎨 Design Elements
- **Premium Color Palette**: Cream, beige, blush pink, and chocolate
- **Typography**: Playfair Display for headings, Lato for body text
- **Animations**: Smooth blob animations, fade-in effects, and bounce effects
- **Responsive Design**: Mobile-first approach, fully responsive layout
- **Modern Interactions**: Hover effects, smooth scrolling, and transitions

### 🚀 Functionality
- **WhatsApp Integration**: Direct order submission via WhatsApp
- **Image Upload**: Drag-and-drop file upload for design references
- **Gallery Filtering**: Real-time gallery filtering by cake type
- **FAQ Accordion**: Expandable FAQ sections
- **Mobile Navigation**: Responsive menu for mobile devices
- **Form Validation**: Client-side form validation
- **Smooth Scroll**: Smooth scrolling throughout the page

### 📱 Mobile Features
- **Mobile-First Design**: Optimized for small screens
- **Responsive Navigation**: Collapsible mobile menu
- **Touch-Friendly**: Large touch targets for mobile users
- **WhatsApp Floating Button**: Fixed button for easy WhatsApp access

## 🛠️ Technical Stack

- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework
- **Vanilla JavaScript**: No dependencies
- **Google Fonts**: Playfair Display & Lato

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/STRATECH23/Baking-bistro.git
```

2. Open `index.html` in your web browser or serve with a local server

3. Customize the following:
   - WhatsApp number in `script.js` and `index.html`
   - Contact details in the contact section
   - Business hours
   - Social media links
   - Gallery items and testimonials

## ⚙️ Configuration

### WhatsApp Integration
Update the WhatsApp number in the following locations:
- `index.html`: Line with WhatsApp button href
- `script.js`: WhatsApp URL generation in form submission

### Contact Information
Update your business details in the Contact Section:
- Phone number
- Email address
- Physical location
- Business hours

### Gallery
Modify the `galleryData` array in `script.js` to add or customize gallery items.

### Testimonials
Update testimonial quotes and client information in the testimonials section.

## 🎨 Customization

### Colors
Edit color variables in `styles.css`:
```css
:root {
    --cream: #FFF8F3;
    --beige: #F5E6D3;
    --blush-pink: #E8C5D5;
    --chocolate: #6B4423;
}
```

### Fonts
Modify Google Fonts import in `index.html` or change font families in CSS.

### Animations
Adjust animation timing and effects in `styles.css` under the Animations section.
